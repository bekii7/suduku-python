# Python Sudoku Game

A fully functional Sudoku game with a graphical user interface built using Python and Tkinter.

## Features

- 9x9 Sudoku grid
- Number input buttons (1-9)
- Input validation
- New game generation
- Solution checking
- Clear board functionality
- Read-only cells for initial numbers

## Requirements

- Python 3.x
- Tkinter (usually comes with Python installation)

## How to Run

1. Make sure you have Python installed on your system
2. Install the requirements:
   ```
   pip install -r requirements.txt
   ```
3. Run the game:
   ```
   python sudoku.py
   ```

## How to Play

1. The game starts with a randomly generated Sudoku puzzle
2. Use the number buttons (1-9) at the bottom to input numbers
3. You can also type numbers directly into the cells
4. The initial numbers are locked and cannot be changed
5. Use the "Check Solution" button to verify your progress
6. Use "New Game" to start a new puzzle
7. Use "Clear" to reset the current puzzle to its initial state

## Game Rules

- Fill the 9x9 grid with numbers 1-9
- Each row must contain all numbers 1-9 without repetition
- Each column must contain all numbers 1-9 without repetition
- Each 3x3 box must contain all numbers 1-9 without repetition # suduku-python
